I built a minimal, privacy-friendly, containerizable web app called "Srimaata" for prenatal care. It includes:
- A clean, responsive static frontend (Home / About / Services / Contact / Book a Session) — optimized and lightweight
- Backend API (Express) with robust appointment storage
- DB support: defaults to SQLite (file), optional PostgreSQL server (via DATABASE_URL)
- Optional Razorpay payment integration (server + client), placeholder flows included
- Dockerfile + docker-compose.yml for local containerized run
- Small smoke test and helpful scripts to get started

What I added (high-level)
- Backend: server.js — endpoints:
  - GET /api/health
  - GET /api/config
  - GET /api/appointments
  - GET /api/appointments/:id
  - POST /api/appointments
  - POST /api/payment/create-order (Razorpay order creation endpoint — requires server keys)
- DB: db.js — single helper that supports sqlite (default) or Postgres when `DATABASE_URL` set
- Frontend: index.html, style.css, app.js, images
- Containerization & docs: Dockerfile, docker-compose.yml, .env.example, README.md
- Tests: simple smoke test smoke.js and helper script start_and_test.ps1
- Project metadata: package.json

How to run (quick start)

Local (node)
1. Install
```powershell
# Windows PowerShell
cmd /c "npm install"
```
2. Start server
```powershell
# Start in foreground
cmd /c "npm start"
# or dev with auto-reload
cmd /c "npm run dev"
```
3. Open in a browser:
http://localhost:3000

Containerized (Docker + Postgres)
1. Start services
```powershell
docker compose up --build
```
2. (Optional) To use the provided Postgres DB, set DATABASE_URL in your environment (example):
postgresql://postgres:example@db:5432/srimaata

Configure Razorpay payments
- Add keys to environment (server-side):
  - RZP_KEY_ID
  - RZP_KEY_SECRET
- You can set these in your host environment or docker-compose (see .env.example)
- When the public key is present, the site will load Razorpay Checkout and the server will create orders.

Persistent storage
- Default: SQLite file srimaata.sqlite (created automatically)
- Optional: Postgres (set DATABASE_URL) — docker-compose includes a Postgres service for convenience

Where to look (main files)
- Backend: server.js, db.js
- Frontend: index.html, style.css, app.js
- Container: Dockerfile, docker-compose.yml
- Docs: README.md, .env.example
